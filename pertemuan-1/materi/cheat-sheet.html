Cheat Sheet HTML

Contekan cepat: struktur dasar, tag judul dan paragraf, aturan tag, dan cara membuka file HTML.

Struktur Dasar HTML

<!DOCTYPE html>
<html>
  <head>
    <title>Judul Tab</title>
  </head>
  <body>
    <!-- Isi di sini -->
  </body>
</html>

Tips: Simpan dengan nama index.html

Aturan Tag HTML

Yang Benar:

<p>Halo dunia!</p>

Yang Salah:

<p>Halo dunia!
  • ✓ Selalu tutup tag yang kamu buka
  • ✓ Tulis tag dengan huruf kecil
  • ✓ Perhatikan indentasi (spasi)
  • ✗ Jangan lupa </ untuk menutup

Contoh Website Lengkap

<!DOCTYPE html>
<html>
  <head>
    <title>Website Saya</title>
  </head>
  <body>
    <h1>Nama Saya Budi</h1>

    <h3>Tentang Saya</h3>
    <p>Umur: 11 tahun</p>
    <p>Kelas: 5 SD</p>

    <h3>Hobi Saya</h3>
    <p>Saya suka bermain game,
    membaca komik, dan
    belajar coding.</p>
  </body>
</html>

Cara Membuka File HTML

Langkah 1: Simpan File

  • Buka Notepad atau VS Code
  • Ketik kode HTML
  • File → Save As
  • Nama: index.html
  • Save as type: All Files

Langkah 2: Buka di Browser

  • Klik kanan file index.html
  • Open with → Chrome/Firefox
  • Atau: Drag & drop ke browser

Tips & Trik

Agar Kode Rapi:

  • Gunakan indentasi (2 spasi)
  • Tutup tag yang kamu buka
  • Tulis komentar: <!-- komentar -->

Kalau Tidak Muncul:

  • Cek: apakah tag sudah ditutup?
  • Cek: apakah di dalam <body>?
  • Refresh browser (F5)
  • Lihat error di Console (F12)

Shortcut Keyboard:

  • Ctrl + S: Save
  • F5: Refresh browser
  • Ctrl + Z: Undo
  • Ctrl + F: Cari teks

Kamus Istilah

  • HTML: Bahasa untuk membuat website
  • Tag: Perintah HTML seperti <h1>
  • Element: Tag + isi + penutup
  • Browser: Aplikasi buka website (Chrome, Firefox)
  • Head: Bagian info website (tidak terlihat)
  • Body: Bagian isi website (terlihat)
  • Heading: Judul dengan tag h1-h6
  • Paragraph: Teks dengan tag p

Latihan Mandiri

Level 1: Mudah

Buat halaman dengan:

  • 1 judul <h1>
  • 2 paragraf <p>

Level 2: Sedang

Buat halaman "Tentang Aku":

  • Nama (h1)
  • Info singkat (h3 + p)
  • Hobi (h3 + p)
  • Cita-cita (h3 + p)

Level 3: Tantangan

Buat halaman "Cerita Liburan":

  • Judul cerita
  • Minimal 3 paragraf
  • Pakai heading untuk subjudul
  • Pakai <br> untuk puisi
