Apa itu HTML?

HTML = HyperText Markup Language
(Bahasa untuk membuat website)

  • HTML itu seperti Tulang atau Pondasi Rumah.
  • Tanpa HTML, website tidak bisa berdiri.
  • Semua website di dunia pakai HTML!

Analogi Mudah:
HTML = Rumah | CSS = Cat & Dekorasi | JavaScript = Listrik & Perabot

Browser: Jendela ke Dunia Website

Browser adalah aplikasi untuk membuka website. Seperti jendela untuk lihat rumah HTML kita!

Struktur Wajib HTML

Setiap membuat web, harus ada kode ini:


<!DOCTYPE html>
<html>
  <head>
    <title>Judul di Tab Atas</title>
  </head>
  <body>
    <!-- Isi website di sini -->
  </body>
</html>
  • <html> : Rumah besar yang bungkus semua
  • <head> : Kepala/otak (info website)
  • <body> : Badan (isi yang terlihat)

Tips: Simpan file dengan nama index.html

Mengenal TAG HTML

Tag adalah tanda khusus dalam HTML. Selalu ada pembuka dan penutup:


<namatag> Isi konten </namatag>

Benar

<p>Halo!</p>

Salah

<p>Halo!

(Tidak ada penutup)

Ingat! Kalau buka tag, jangan lupa tutup!

Kamus Kode Hari Ini

<h1>

Judul Paling Besar
(Heading 1)

<h2>, <h3>

Judul Sedang
(Heading 2, 3)

<p>

Paragraf
(untuk tulisan panjang)

<br>

Ganti Baris
(Break - tanpa penutup)

Ada 6 jenis heading: <h1> sampai <h6>
<h1> paling besar, <h6> paling kecil!

Tantangan: Website Tentang Aku

Buatlah 1 file bernama index.html yang isinya:

  1. Nama Lengkapmu (pakai <h1>)
  2. Umur & Kelas (pakai <h3>)
  3. Cerita pendek tentang hobimu (pakai <p>)
  4. BONUS: Tambahkan cita-citamu!

Langkah-langkah:

  1. Buka Notepad atau VS Code
  2. Ketik kode HTML-mu
  3. Save as index.html
  4. Buka file dengan Chrome

Waktu: 15 menit | Tanya kalau ada yang bingung!
