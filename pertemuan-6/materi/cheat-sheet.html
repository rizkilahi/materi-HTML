Kotak & Tombol

Contekan cepat: tag baru, gaya kotak, contoh kode, dan cara memperbaiki kesalahan.

Alur Cepat Belajar Hari Ini

  1. Website = kumpulan kotak: kepala, menu, isi, kaki
  2. Buat kotak dengan <div>
  3. Hias kotak dengan style
  4. Jajarkan kotak dengan display: flex
  5. Buat tombol dari link <a> yang dihias

Tag Baru

Tag Fungsi Contoh
<div> Kotak pembungkus (wadah) <div>...isi...</div>
<button> Tombol (nanti dipakai bersama JavaScript) <button>Klik Aku</button>
<a> + style Tombol yang bisa pindah halaman <a href="hobi.html" style="...">Hobi</a>

Kamus Gaya Kotak

Gaya Artinya Contoh
background-color Warna isi kotak background-color: pink;
color Warna tulisan color: white;
border Garis pinggir (tebal, jenis, warna) border: 3px solid purple;
border-radius Sudut membulat border-radius: 12px;
padding Jarak di dalam kotak (isi ke garis) padding: 15px;
margin Jarak di luar kotak (ke kotak lain) margin: 10px;
width Lebar kotak width: 200px;
text-align Posisi tulisan text-align: center;
display: flex Isi kotak berjajar ke samping Ditulis di kotak pembungkus
gap Jarak antar kotak yang berjajar gap: 10px;
text-decoration: none Menghapus garis bawah link Wajib untuk tombol dari <a>

Contoh Kartu

<div style="background-color: lightyellow; border: 3px solid orange; border-radius: 12px; padding: 15px;"> <h3>Kucingku</h3> <p>Namanya Oyen.</p> </div>

Kucingku

Namanya Oyen.

Contoh Kotak Berjajar

<div style="display: flex; gap: 10px;"> <div style="background: pink; padding: 10px;">🍕 Pizza</div> <div style="background: lightblue; padding: 10px;">🍜 Mie</div> <div style="background: lightgreen; padding: 10px;">🍩 Donat</div> </div>
🍕 Pizza
🍜 Mie
🍩 Donat

Contoh Tombol

<a href="hobi.html" style="background-color: hotpink; color: white; padding: 10px 20px; border-radius: 20px; text-decoration: none;">Lihat Hobiku</a> <button>Klik Aku</button>
Lihat Hobiku   

Kerangka Layout 4 Bagian

<div> KEPALA: judul website </div> <div> MENU: tombol-tombol </div> <div style="display: flex;"> <div> KARTU 1 </div> <div> KARTU 2 </div> </div> <div> KAKI: Dibuat oleh ... </div>

Palet Warna Rekomendasi

hotpink purple teal orange lightyellow lightblue lightgreen lavender #fdf2f8

Tips warna: kotak besar pakai warna muda (light...), tombol dan kepala pakai warna tua dengan tulisan putih supaya mudah dibaca.

Troubleshooting Cepat

Masalah Penyebab Solusi
Semua bagian ikut berwarna sama Ada </div> yang lupa Hitung jumlah <div> dan </div>, harus sama
Kartu tidak berjajar display: flex salah tempat Pindahkan ke div pembungkus kartu
Gaya tidak berubah Lupa : / ; / tanda kutip Tulis style="nama: nilai; nama: nilai;"
Tombol bergaris bawah Gaya bawaan link Tambah text-decoration: none;
Tulisan mepet ke garis Belum ada padding Tambah padding: 15px;
Kotak saling menempel Belum ada jarak Tambah margin atau gap

Checklist Final

  • Ada 4 bagian: kepala, menu, isi, kaki
  • Minimal 2 tombol menu
  • Minimal 2 kartu ranking berjajar, tiap kartu berisi <ol> top 3
  • Semua <div> sudah ditutup
  • Warna nyaman dibaca

Tips presentasi: tunjukkan kartu ranking favoritmu dan ceritakan kenapa juara nomor 1 pantas menang!
