Daftar Pertemuan

Setiap pertemuan punya slide presentasi, template tugas, dan cheat sheet.

  1. 01

    Dasar HTML

    Kenalan dengan website, browser, dan struktur HTML. Membuat halaman "Tentang Aku".

    • <html>
    • <head>
    • <body>
    • <h1>
    • <p>
    • <br>
    Presentasi Template Tugas Cheat Sheet
  2. 02

    Gambar & Warna

    Memasang gambar, mewarnai tulisan dan latar, serta gaya tebal, miring, garis bawah.

    • <img>
    • style="color"
    • background-color
    • <b> <i> <u>
    Presentasi Template Tugas Cheat Sheet
  3. 03

    Link & Navigasi

    Menghubungkan halaman dengan link dan membuat menu untuk website beberapa halaman.

    • <a href>
    • target="_blank"
    • menu navigasi
    Presentasi Template Tugas Cheat Sheet
  4. 04

    Mini Project & Presentasi

    Merapikan dan menyelesaikan satu website, lalu berlatih menceritakannya di depan kelas.

    • review semua tag
    • presentasi 60 detik
    Presentasi Template Tugas Cheat Sheet
  5. 05

    List & Tabel

    Menyusun data dengan daftar berpoin, daftar bernomor, dan tabel. Membuat Profil Kelas.

    • <ul>
    • <ol>
    • <li>
    • <table>
    • <tr> <th> <td>
    Presentasi Template Tugas Cheat Sheet
  6. 06

    Kotak & Tombol

    Menyusun halaman dari kotak-kotak dan membuat tombol menu. Membuat Website Ranking Favoritku.

    • <div>
    • padding / margin
    • display: flex
    • tombol
    Presentasi Template Tugas Cheat Sheet
