Pertemuan 5 · Template Tugas

Profil Kelas Saya

Susun data kelasmu dengan list dan tabel.

Instruksi: Isi bagian berikut dengan data kamu sendiri.

  • Buat 1 unordered list (<ul>)
  • Buat 1 ordered list (<ol>)
  • Buat 1 tabel minimal 3 baris data

Langkah 1: Rencana Halaman

Judul halaman: ____________________

Tema data: ____________________

3 hobi favorit: ____________________

3 kegiatan pagi: ____________________

Kolom tabel: ____________________

Jumlah baris data: ____________________

Warna tema: ____________________

Bagian tersulit: ____________________

1) Hobi Favorit (Unordered List)

<ul> <li>[Hobi 1]</li> <li>[Hobi 2]</li> <li>[Hobi 3]</li> </ul>

2) Jadwal Pagi (Ordered List)

<ol> <li>[Kegiatan 1]</li> <li>[Kegiatan 2]</li> <li>[Kegiatan 3]</li> </ol>

3) Data Teman (Tabel)

<table> <tr> <th>Nama</th> <th>Umur</th> <th>Hobi</th> </tr> <tr> <td>[Nama 1]</td> <td>[Umur]</td> <td>[Hobi]</td> </tr> </table>

Checklist Debug Cepat

  • Setiap item list sudah berada di dalam tag <li>
  • Jumlah kolom header sama dengan jumlah kolom data
  • Tidak ada tag tabel yang tertinggal
  • Judul halaman mudah dipahami
  • Warna dan jarak sudah nyaman dibaca

Penilaian Diri (Centang)

Aspek Belum Sudah
UL berisi minimal 3 item
OL berisi minimal 3 langkah
Tabel berisi minimal 3 baris data
Data rapi dan mudah dibaca
