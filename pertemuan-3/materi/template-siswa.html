Pertemuan 3 · Template Tugas

Website Multi-Halaman

Tiga halaman yang saling terhubung lewat menu navigasi. File ini adalah halaman utamanya.

Buat website dengan 3 halaman yang saling terhubung:

  1. index.html - Halaman utama (file ini)
  2. hobi.html - Halaman tentang hobi kamu
  3. favorit.html - Halaman tentang hal favorit kamu

Yang Harus Ada di Setiap Halaman:

  • Menu navigasi dengan link ke 3 halaman
  • Judul halaman yang jelas
  • Konten yang menarik (pakai gambar dan warna!)
  • Minimal 1 link ke website luar

Contoh kode menu navigasi:

<nav style="text-align: center; padding: 15px; background: lightblue;">
  <a href="index.html">Home</a> | 
  <a href="hobi.html">Hobi Saya</a> | 
  <a href="favorit.html">Favorit Saya</a>
</nav>

Contoh link ke website luar:

<a href="https://youtube.com" target="_blank">Ke YouTube</a>
