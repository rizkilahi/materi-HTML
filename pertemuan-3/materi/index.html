1. Apa itu Link?

Link (tautan) adalah jembatan yang menghubungkan satu halaman dengan halaman lain!

Contoh Link yang sering kamu klik:

  • Menu di website (Home, About, Contact)
  • Tombol "Baca Selengkapnya"
  • Link ke YouTube, Google, dll

Tag untuk Membuat Link

Menggunakan tag <a> (anchor = jangkar)


<a href="https://google.com">Klik di sini!</a>

HASIL

Klik di sini!
Penting: Tag <a> harus ada href (hypertext reference) yang berisi alamat tujuan!

Bedah Kode Link


<a href="https://google.com">Klik di sini!</a>
  • <a> : Tag anchor (pembuat link)
  • href="..." : Alamat tujuan link
  • Klik di sini! : Teks yang bisa diklik
  • </a> : Penutup tag (jangan lupa!)

2. Jenis-jenis Link

A. Link ke Website Lain


<a href="https://youtube.com">Ke YouTube</a>
<a href="https://wikipedia.org">Ke Wikipedia</a>

B. Link ke Halaman Sendiri


<a href="about.html">Tentang Saya</a>
<a href="hobi.html">Hobi Saya</a>

Membuka Link di Tab Baru

Tambahkan target="_blank"


<a href="https://google.com" target="_blank">
  Buka Google di Tab Baru
</a>

Kapan pakai target="_blank"?

  • Link ke website lain (agar pengunjung tidak keluar dari website kita)
  • Link ke PDF atau dokumen

3. Membuat Menu Navigasi

Menu navigasi = kumpulan link yang rapi


<nav>
  <a href="index.html">Home</a> | 
  <a href="tentang.html">Tentang</a> | 
  <a href="galeri.html">Galeri</a> | 
  <a href="kontak.html">Kontak</a>
</nav>
Home | Tentang | Galeri | Kontak

Mewarnai Link

Link juga bisa dikasih warna dan style!


<a href="home.html" style="color: red;">Home Merah</a>

<a href="about.html" style="color: blue; text-decoration: none;">
  About Tanpa Garis Bawah
</a>

Style Link yang Umum:

  • text-decoration: none; → Hilangkan garis bawah
  • color: blue; → Ubah warna
  • font-weight: bold; → Buat tebal

Tips & Trik Link

Yang Baik:

  • Gunakan teks yang jelas: "Lihat Galeri Foto" lebih baik dari "Klik di sini"
  • Pastikan link berfungsi (cek alamatnya)
  • Link ke website lain pakai target="_blank"

Yang Perlu Dihindari:

  • Link yang tidak jelas tujuannya
  • Terlalu banyak link dalam satu paragraf
  • Lupa tutup tag </a>

Misi Hari Ini: Website Multi-Halaman

Buat website dengan 3 halaman yang saling terhubung:

  1. index.html - Halaman utama dengan menu navigasi
  2. hobi.html - Halaman tentang hobi kamu
  3. favorit.html - Halaman tentang hal favorit kamu

Yang harus ada:

  • Menu navigasi di setiap halaman
  • Minimal 1 link ke website luar (YouTube, Wikipedia, dll)
  • Gunakan warna dan gambar yang menarik

Selesai!

Sekarang website kalian bisa punya banyak halaman yang saling terhubung!
