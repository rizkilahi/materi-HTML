Pertemuan 2

Mewarnai Web

Menambahkan Gambar, Warna, dan Gaya Tulisan

Usia 11 Tahun · 2 Jam

Review Dulu Yuk!

Minggu lalu kita belajar apa?

  • <h1> untuk apa? → Judul Besar
  • <p> untuk apa? → Paragraf
  • <br> untuk apa? → Ganti Baris

1. Memasukkan Gambar

Supaya tidak bosan tulisan terus, ayo pasang foto!

Kodenya:


<img src="kucing.jpg" width="300px">
PENTING:
File gambar harus ada di FOLDER YANG SAMA dengan file HTML kamu.

Bedah Kode Gambar

  • <img> : Tag Image (Gambar).
  • src="..." : Source (Nama file gambarnya).
  • width="..." : Lebar gambar (biar tidak kegedean).

*Uniknya, tag img tidak perlu penutup </img> lho!

2. Memberi Warna

Jangan hitam putih terus! Gunakan atribut style.


<h1 style="color:red">Halo Merah!</h1>

<p style="color:blue">Paragraf ini warnanya biru.</p>

Bisa pakai bahasa Inggris: red, green, blue, pink, orange, purple.

Warna Latar Belakang

Kita bisa mewarnai latar belakang tulisan, atau bahkan satu halaman penuh!


<h1 style="background-color:yellow">Stabilo Kuning</h1>

<body style="background-color:lightblue">
  ...isi web...
</body>

Ingat: background-color

3. Gaya Tulisan (Formatting)

Biar tulisan makin keren:

  • Tebal (Bold) : <b>tebal</b>
  • Miring (Italic) : <i>miring</i>
  • Garis Bawah (Underline) : <u>garis</u> 


<p>Saya <b>sangat</b> suka makan <i>Nasi Goreng</i>!</p>

Misi Hari Ini: Website Favoritku

Buat halaman baru tentang Kartun / Hewan Kesukaanmu yang berisi:

  1. Judul nama karakter/hewan (Warna-warni).
  2. Foto karakter tersebut (img).
  3. Penjelasan kenapa kamu suka (Gunakan Tebal atau Miring).
  4. Warna background halaman jangan putih!

Selesai!

Sekarang website kalian sudah berwarna.
